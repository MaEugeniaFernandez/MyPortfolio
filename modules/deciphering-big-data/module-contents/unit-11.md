This unit introduced the core principles of transaction processing by examining ACID properties and their effects on the transaction cycle, alongside an analysis of scheduled transactions, system failures, and the critical role of checkpoints in database recovery.

The main activity for this unit was the individual project, in which I put into practice the database design proposed by my team in Unit 6. Working on my own, I used Gemini to help generate the Python code, detect the dataset’s structure and clean the hospital readmission data, and then built an interactive dashboard in Tableau Public to visualise the validated data. Building the solution hands-on revealed significant data-quality issues that the design phase had not uncovered, which showed me how important human oversight is when working with AI-assisted tools.

From this unit’s readings I refreshed some basic Python concepts, and learned more about the use of Pandas, NumPy and Jupyter for data wrangling with Python. I also learned about database transactions, which was a completely new topic for me, so it was something different but still interesting to learn this week.
