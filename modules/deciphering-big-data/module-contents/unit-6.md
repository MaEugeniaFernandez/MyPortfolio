This unit explored relational database design and integrity by evaluating how cleaning methods contribute to the storage of usable datasets, and by examining database creation, the use of key fields for linking records, the impact of anomalies on database integrity, and the rationale behind applying different normal forms for data normalisation.

This unit taught me key basic concepts related to database design that were new to me, so it was necessary for me to follow the lecturecast very carefully to learn everything, which was also super interesting.
