This unit explored relational database design and integrity by evaluating how cleaning methods contribute to the storage of usable datasets, and by examining database creation, the use of key fields for linking records, the impact of anomalies on database integrity, and the rationale behind applying different normal forms for data normalisation.

The main activity for this unit was the team project, in which our group of four designed an AI-assisted logical database for a healthcare organisation, using a hospital readmission dataset to analyse readmissions and resource use. Working with ChatGPT and Gemini on Google Colab, we designed the database, the data processing workflows and a prototype dashboard tracking readmission rates, length of stay, waiting times and bed occupancy. Each team member took responsibility for one part of the report, and the project received very positive feedback from our tutor.

This unit taught me key basic concepts related to database design that were new to me, so it was necessary for me to follow the lecturecast very carefully to learn everything, which was also super interesting.
